# 数学练习题生成器

> 儿童加减乘除练习题生成器 — **A4 可打印**，适合家长/老师快速出卷。

![alt text](math.png)

## 功能

- 支持 **加法**、**减法**、**乘法**、**除法**、**混合运算**
- 三级范围：20以内 / 50以内 / 100以内
- 可配置每页题量、页数、列数（2/3/4 列）
- **进位加法 / 借位减法**：可设比例（0–100%），可选显示「进位」「借位」提示
- 答案显示：不显示 / 每题后 / 尾页汇总
- 可设置随机种子，同一种子生成相同题目（方便多次印刷）
- 实时预览，A4 打印样式（`@media print` 优化）
- 零依赖，打开即用

## 使用

1. 直接打开 `index.html`，或在 GitHub Pages 上访问
2. 在控制面板选择参数，点「重新生成」
3. 点「打印」或浏览器打印功能输出

## 技术栈

纯 HTML + CSS + JavaScript，无任何外部依赖。
